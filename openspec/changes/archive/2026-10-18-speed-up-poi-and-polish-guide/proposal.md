# Proposal · 补点提速 + 指南可读性 + 航点自动显示

## Why

用户实测 7 条反馈，其中三条是功能性故障：

1. **补点很久都不行**：实测 Overpass 查询从 42 秒涨到 **120 秒以上**。
   根因是主查询用了 `out geom tags`，把水域面的全部顶点都拉了回来。
2. **对话入口没了**：对话面板只在有地名点时才出现，补点失败时连带消失。
3. **回放页导入 GPX 看不到航点**：航点需要手动点「KML 路径点」才渲染，
   GPX 用户根本不知道要这么做。

另有三条体验问题：指南显示 Markdown 源码、AI 写通用装备套话、
风险只说「4 处发卡弯」却不说在哪。

## What Changes

- **补点分层查询**：主查询只取节点（`out tags`），河流几何单独一次且可失败跳过。
- **代理自愈**：重试时轮换 mihomo 的 7890/7893/7891，代理挂掉也能恢复。
- **对话入口常驻**：没有地名点时显示禁用态并提示先补点，而不是隐藏。
- **航点自动显示**：回放页导入带 `wpt` 的 GPX 后自动画点，不再要求手动点按钮。
- **指南渲染 Markdown**：迷你渲染器输出标题/表格/列表，不再是源码。
- **提示词去套话**：禁止「导入手机」「保持离线」这类通用建议；
  装备只在天气/地形相关时提（降雪→防滑、降雨→防水、大风低温→保暖、攀爬→手套）。
- **风险带位置**：转向提示附上里程，便于在地图上定位。
- **补充信息输入**：指南可填写「几点到登山口、商团轻装还是自背负」等，带给模型一起分析。

## Capabilities

### Modified Capabilities

- `poi-enrichment`：主查询只取节点；河流几何单独查询且可降级。
- `conversion-projects`：对话入口常驻；指南支持补充信息与 Markdown 渲染。
- `track-playback`：导入带航点的 GPX 自动标点。
- `trip-briefing`：提示词约束去套话、装备随天气；风险附里程。
