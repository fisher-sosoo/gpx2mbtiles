# Proposal

## Why

出图的时间信息太粗：只有总耗时，看不出休息占了多少；图头只能沿用 GPX 里的
轨迹名（Garmin 导出常常就是一串日期时间），想换成自己的名字没有办法；
标题下面只给了开始时间，结束时间同样有用，而「多少个轨迹点」没人关心。
另外参考图里还有爬升 / 平路 / 下降的比例——这正是判断一条路线是
「硬爬升」还是「缓坡长下」的关键，现在缺这块。

## What Changes

- 页面加「标题名称」输入框：留空用文件里的轨迹名，填了就替换大标题，
  下载文件名也跟着走。
- 图头副标题改为「开始 <时间> → 结束 <时间>」，**去掉轨迹点数**。
- 总览补充 **运动时间 / 静止时间**（按移动速度阈值拆分，两者之和等于总耗时）
  与 **累计下降**。
- 新增 **坡度构成** 区块：按约 100m 滑动窗口算坡度，> +3% 记爬升、
  < -3% 记下降、其余记平路；给出三者占比、公里数与一条分段色条。
- 顺带把「版面顺序」里过时的「配速曲线 / 1km 分段表」更正为
  「速度曲线 / 自适应分段表」。
