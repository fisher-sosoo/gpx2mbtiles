# Design

## Context

回放页已有一套成熟的 canvas 出图（自己按地理坐标绘制，不用 html2canvas，
因为它会把 SVG 轨迹丢掉、还会把缩放控件画进去）。本轮把它精简后搬到转换页。

## Goals / Non-Goals

**Goals:**

- 本页看地图、圈风险点、出图，一步到位。
- 不改动服务端渲染，不给镜像加依赖。

**Non-Goals:**

- 不做回放页那样完整的工具层（里程桩/箭头/图例拖动）。
- 不做离线瓦片（底图仍走在线瓦片）。

## Decisions

### D1 · 复用 canvas 逐层绘制，不用 html2canvas

回放页的历史结论：html2canvas 对 Leaflet 的跨 pane SVG 支持很差，
结果是「只有底图和文字、轨迹整条丢失」。自己按经纬度投影后逐层画反而准确。

绘制顺序：底色 -> 瓦片 -> 轨迹(白描边+主线) -> 风险圈 -> 地名点 -> 标题条 -> 版权。

### D2 · 风险圈半径跟转角走

>=120° 用大圈（16px），其余用 11px。让人一眼看出哪个更值得停一下。

### D3 · 出图尊重当前图层开关

用户关了风险圈还把它画进图里，等于骗人。导出时读同样的 checkbox 状态。

### D4 · 瓦片跨域与失败

瓦片用 `crossOrigin=anonymous` 拉取以便写入 canvas；单张失败返回 null 跳过，
不整体失败 —— 缺一块底图也好过没有图。

### D5 · 地图失败不阻断

画图依赖再取一次 GPX；这一步失败只影响地图，其它区块照常。

## Risks / Trade-offs

- **[CORS 导致 canvas 污染]** → OpenTopoMap 允许跨域瓦片；若某天不允许，
  toBlob 会抛异常，已捕获并提示，不影响页面其它功能。
- **[移动端地图高度]** → 固定 360px，小屏也能看到轨迹全貌。
- **[重复取 GPX]** → 转换响应里已含 gpx 文本，可直接复用；本轮先走接口取，
  后续可优化为直接复用响应体。
